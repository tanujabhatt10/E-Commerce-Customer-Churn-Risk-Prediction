# E-Commerce-Customer-Churn-Risk-Prediction
Project Overview

This project focuses on analyzing e-commerce customer purchase behavior and predicting customer churn risk using Machine Learning techniques.

Objectives

- Analyze customer purchase behavior.
- Explore customer churn patterns.
- Perform data preprocessing and exploratory data analysis.
- Build and evaluate machine learning models.
- Identify customers at high risk of churn.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Machine Learning Models

- Logistic Regression
- Random Forest Classifier

Model Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

Key Outcomes

- Analyzed customer purchasing patterns.
- Compared two machine learning models.
- Generated customer churn risk predictions.
- Identified potential business strategies for customer retention.

Conclusion

This project demonstrates the application of machine learning in understanding customer behavior and predicting churn risk. The insights can help e-commerce businesses improve customer retention strategies.
